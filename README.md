## 🌟 Why Choose CIPHER-MD?

Standard WhatsApp bots can only reply to simple commands. **CIPHER-MD** takes it to an entirely different level:

- 🕵️ **Total Data Privacy:** Most bots process your messages on a central server. CIPHER-MD is designed to be **self-hosted**, meaning your chats, data, and sessions stay 100% with you.
- 🧠 **Beyond Chat - True AI Agents:** This isn't just an AI that talks. Our highly capable **AI Agents** have access to powerful tools. They can dynamically search the web, read GitHub repos, generate images, convert currencies, and even read, reply to, and search your **Gmail inbox** right from WhatsApp!
- ⚙️ **Ultimate Customization:** You are not locked into one AI. Through a simple configuration, you can choose exactly which AI model (Gemini, ChatGPT, or Groq) handles regular chats and which one handles complex Agent tasks.
- 🚀 **Extreme Performance & Security:** Engineered for heavy lifting, the core handles media processing and code sandboxing effortlessly, all protected by an advanced DRM secure kernel.

## 🚀 Setup & Deployment Guide

Follow these exact steps to get your CIPHER-MD bot up and running smoothly:

### 1️⃣ Fork the Repository
First, you need to fork this repository to your own GitHub account.
👉 **[Click Here to Fork](https://github.com/sh4lu-z/Cipher-MD/fork)**

### 2️⃣ Connect Bot & Get Session ID
Connect the bot to your WhatsApp account. Once successfully connected, you will receive your unique `SESSION_ID`.
👉 **[Connect Bot & Get Session ID](https://cipher-md.syntiox.top/connect)**

### 3️⃣ Set Up Variables
Before deploying, make sure you have the following 3 **mandatory variables** ready:

```env
# 🔴 REQUIRED VARIABLES 🔴
MONGO_URL=your_mongodb_connection_string
SESSION_ID=your_session_id_here
PAIRING_NUMBER=your_whatsapp_number
```
> 💡 **NOTE:** To see the full list of advanced variables you can configure, check the **[Full Deployment Guide](https://cipher-md.syntiox.top/deployment)**.

### 4️⃣ Deploy Bot
