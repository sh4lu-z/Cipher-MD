## 🌌 Overview
**CIPHER-MD** is a high-performance, multi-functional WhatsApp AI bot built by **[sh4lu-z](https://github.com/sh4lu-z)**. It integrates advanced AI models (Gemini, Groq, OpenAI) and heavy media processing tools to deliver a seamless automated experience right to your WhatsApp inbox.

## ⚡ Key Features
- 🛡️ **100% Privacy (Self-Hosted):** Run CIPHER-MD on your own server. You own your data.
- 🤖 **Autonomous AI Agents:** AI that can browse the web, parse documents, and manage your Gmail automatically.
- 🎛️ **Customizable AI Platforms:** Switch between **Google (Gemini)**, **Groq**, and **OpenAI** seamlessly.
- ⌨️ **100+ Core Commands:** Massive library from utilities to fun mini-games.
- 🎙️ **Speech-to-Text:** Instant voice note transcription powered by AssemblyAI.
- 🖼️ **Media Core:** Sticker creation, image manipulation, and AI image generation.
- 🔒 **Secure Kernel:** Built-in DRM and integrity checks.

## 🚀 Quick Start Guide

### 1️⃣ Fork the Repository
You must fork this repository to your GitHub account before deploying.
👉 **[Fork CIPHER-MD](https://github.com/sh4lu-z/Cipher-MD/fork)**

### 2️⃣ Connect to WhatsApp
Link the bot to your WhatsApp account to get your unique `SESSION_ID`.
👉 **[Get Session ID](https://cipher-md.syntiox.top/connect)**

### 3️⃣ Configure Environment
Set up your `.env` variables. Here are the mandatory ones:
```env
MONGO_URL=your_mongodb_connection_string
SESSION_ID=your_session_id_here
PAIRING_NUMBER=your_whatsapp_number
```

### 4️⃣ Deploy
Follow the official documentation to deploy correctly (Docker, Koyeb, VPS, etc.).
👉 **[Official Deployment Guide](https://cipher-md.syntiox.top/deployment)**
