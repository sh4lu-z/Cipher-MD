# Security Policy

## Supported Versions

Since this project has a strict non-modification and auto-update policy (DRM protected), only the latest version deployed via the official channels is supported. 

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within CIPHER-MD, please send an e-mail to **hello@shalukagimhan.com**.

**Please do not report security vulnerabilities through public GitHub issues.**

All security vulnerabilities will be promptly addressed.

## System Integrity & DRM

As stated in the Terms of Use and the DRM & Security Notice in our `README.md` and `LICENSE.md`:
- Modification of this core engine is strictly prohibited.
- If the `LICENSE` is modified, tampered with, or removed, the bot will automatically self-lock and stop working immediately. 
- You are not allowed to edit, modify, or re-brand any part of this source code.

Bypassing these security checks is a violation of the EULA and will result in the immediate termination of your license to use CIPHER-MD.
